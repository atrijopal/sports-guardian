## Project Overview

This is **Module 1** of a sports media "Digital Asset Protection" hackathon demo — a multi-layer video fingerprinting system. It identifies whether a suspect clip was ripped from a protected source video, even after heavy modification (mirroring, cropping, recoloring, speed changes, muting, logo overlays, re-encoding).

**Target machine:** Windows with `ffmpeg` and `fpcalc` in PATH.

## Running the Server

```bash
# Create and activate virtualenv
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Start the server
uvicorn app:app --reload
# Browse to http://localhost:8000
```

## Architecture

### Four-Layer Fingerprinting Pipeline

**Layer 1 — Visual pHash** (`fingerprint/layer1_visual.py`)
Extracts frames via FFmpeg, runs each through `normalize.py` (letterbox strip → center crop → resize → logo mask → histogram equalize), then computes pHash. Mirror canonicalization: stores the lexicographically smaller hash of the frame vs. its horizontal flip.

**Layer 2 — Audio Chromaprint** (`fingerprint/layer2_audio.py`)
Extracts audio via FFmpeg as 44.1kHz mono WAV, runs through `fpcalc -raw`, then uses sliding-window XOR-distance matching to locate the suspect clip within the original's fingerprint. Gracefully returns 0.0 for muted clips.

**Layer 4 — Match DNA** (`fingerprint/layer4_dna.py`)
Extracts 1-Hz visual and audio energy signals, detects peaks with scipy, encodes peaks as characters ('V'/'A') separated by quantized gap buckets ('s'/'m'/'l' for <3s, 3–8s, >8s). Fuzzy substring match via `rapidfuzz.fuzz.partial_ratio`. Speed invariance comes from the ratio encoding, not absolute gaps.

**Fusion** (`fingerprint/fusion.py`)
Weighted average (`config.FUSION_WEIGHTS`) + minimum agreeing layers check. Returns per-layer breakdown, verdict string, and natural-language explanation for the UI.

### Data Flow

```
Register:  upload → temp file → Layer1+2+4.generate_fingerprint() → storage.add_fingerprint()
Check:     upload → temp file → Layer1+2+4.generate_fingerprint() → fusion.best_match(suspect, all_originals)
```

### Storage Format

`fingerprints_db.json` is a plain JSON array. Each entry has `video_id`, `name`, `registered_at`, `duration_sec`, and `layer1`/`layer2`/`layer4` fingerprint dicts. Brute-force list search over all registered videos — fine for <20 demo videos.

## Critical Implementation Rules

1. **Wrap all temp files in `try/finally`** — use `tempfile.mkdtemp()` + `shutil.rmtree()`. Never leave junk behind.
2. **All endpoints catch exceptions** and return `{"error": str(e)}` with HTTP 500. No stack traces during live demo.
3. **All paths come from `config.py`** — use `pathlib.Path`, never string concatenation.
4. **Fingerprint functions run in `asyncio.to_thread()`** from FastAPI routes — they're CPU-bound and slow.
5. **`shell=False` in all subprocess calls** — Windows path handling with `shell=True` is unreliable.
6. **Pass paths with `str(Path(x))`** to subprocess to handle Windows paths with spaces.
7. **Log every major step** with `logging` module at `[HH:MM:SS]` granularity — visible in terminal during demo.

## Threshold Tuning

All thresholds live in `config.py`. **Tune thresholds there, not inside layer files.**

Key thresholds to know:
- `L1_HAMMING_MATCH_THRESHOLD = 12` — max Hamming distance for frame match
- `L4_PEAK_PROMINENCE_VISUAL/AUDIO = 0.15` — the #1 Layer 4 tuning knob; target ~1 event per 3–5 seconds
- `FUSION_MATCH_THRESHOLD = 0.55` — overall score cutoff
- `FUSION_MIN_AGREEING_LAYERS = 2` — both overall score AND this must be met

## Known Limitations

- Layer 4 needs clips ≥45 seconds to produce enough events for reliable matching
- Muted clips score 0.0 on Layer 2 (expected — Layers 1+4 compensate)
- Layer 3 (motion) is intentionally not built — mentioned in architecture, skipped in demo
- No FAISS, no Postgres, no auth — JSON file + brute-force list search

## External Dependencies

- `ffmpeg` — frame and audio extraction (https://www.gyan.dev/ffmpeg/builds/)
- `fpcalc` — Chromaprint fingerprinting (https://acoustid.org/chromaprint)

Both must be on Windows PATH before running. If missing: `RuntimeError` from subprocess calls.
