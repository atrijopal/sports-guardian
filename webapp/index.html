Fingerprint Layers
L1
Visual pHash
Mirror-canonical perceptual hash every 5th frame. Survives re-encoding, color grading, logo overlays, compression.
L2
Audio Chromaprint
Sliding-window XOR match on 44.1kHz fingerprint. Locates clips within long broadcasts. Graceful on muted clips.
L4
Event-Peak DNA
1Hz energy peaks encoded as character sequence. Fuzzy substring match via rapidfuzz — speed-change invariant.

Watermarking Layers
L1
Spread Spectrum Visual
Bipolar noise patterns across pixel regions. Bit polarity encodes session ID. Survives re-encoding and compression.
L2
BPSK Audio (19 kHz)
Inaudible tones above human hearing. Repeated every 10s throughout the track. Extracted via bandpass + correlation.
L3
DCT Structural (QIM)
Mid-frequency DCT coefficient nudging. Frequency domain — survives crop, resize, and geometric attacks that defeat L1.
Reed-Solomon ECC — 64-bit session ID + 10 RS symbols. Attribution holds even if ~27% of bits are corrupted by attacks.
